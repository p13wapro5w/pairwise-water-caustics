# pairwise-water-caustics

浅水池塘的折射在相机贴近水面时整片岸线错位，屏幕空间折射用的深度图是上一帧，波浪法线又采样了另一张；水深吸收按固定距离算，没乘视线路径，远处水底反而更清；焦散贴图投影在波浪上，法线翻转时焦散跑到水面以上；泡沫只在屏幕空间边缘生成，物体半沉时泡沫悬空；反射平面相机没跟着主相机裁剪，水外物体倒影穿帮；多相机分屏共用水面网格，左右眼反射矩阵互相覆盖；透明水面排在粒子之后，气泡被水色盖掉；浅水边缘用硬阈值切 alpha，岸线出现锯齿；时域累积在波浪快速变化时没按速度重置，水面拖出条纹；HDR 高光在折射后重复乘，太阳倒影过曝。render/water_refraction.py 是核心，tests/test_water_refraction.py 15个红。要修的是：折射用当前帧深度并统一法线；吸收按视线路径积分；焦散随法线朝向裁剪；泡沫用深度与物体标记；反射相机跟随主相机裁剪；多相机独立水面状态；透明排序按水面层；岸线 alpha 软过渡；时域按波浪速度重置；高光只乘一次。

## 运行

```bash
python -m pytest tests -q
```
